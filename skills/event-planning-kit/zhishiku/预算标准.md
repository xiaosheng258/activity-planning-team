# 社团活动预算标准

> 供预算分析师（budget-analyst）检索。**所有单价必须从此处取，不要凭模型记忆估价。**
>
> 适用范围：**学生社团活动**，经费由社团联合会独立管理，主力规模 30-80 人。

## 核心原则：预算按实际需求算，不套固定额度

**本社团没有固定的单次活动经费额度，每次活动按实际需要编制。**

因此你的工作方式是：

1. **先问清本次可用多少**（用户说了就按用户的，没说就按活动规模合理测算）
2. 按「实际要办成什么样」倒推所需金额，**不要为了贴近某个档位而删减必需项**
3. 如果测算结果明显超出用户预期，给出**分级压缩方案**（保底版 / 标准版 / 完整版），让用户自己选
4. 用户没给总额时，在预算表末尾标注「建议申报额度」

> ❌ 不要写"破冰活动应在 300-800 元之间"这种话——这是套模板，不是算预算。
> ✅ 正确做法：算出 1,529 元，然后说明"若需控制在 800 元内，可执行【保底版】：砍掉钥匙扣与零食降档，剩 719 元"。

## 一、社团经费规则

| 项目 | 说明 |
|------|------|
| 经费来源 | 社团联按学期拨付 + 会费 + 赞助，**具体额度每学期由社团联核定** |
| 申请方式 | 活动前提交《活动经费申请表》，**需附预算明细** |
| 审批链 | 社长签字 → 指导老师知会 → 社团联财务审批 |
| 拨付方式 | 多数为**先垫付后报销**，少数可预支；**以社团联当期规定为准** |
| 报销凭证 | 发票 + 清单 + 签到表（证明实际发生） |
| 结余处理 | 顺延至下次活动，不得挪作他用 |

> **执行含义**：预算表必须"能报销"——每项要有采购来源、单价能对上、数量能说清。写"其他费用 500 元"会被打回。

## 二、按活动类型的支出构成（不是额度，是结构）

不同的活动，钱花在不同地方。以下是**结构比例**参考，用于校验你的预算是否离谱：

| 活动类型 | 主要支出项 | 次要支出项 | 通常不需要 |
|---------|-----------|-----------|-----------|
| 内部例会/培训 | 打印材料、茶歇 | — | 奖品、场地、设备 |
| 内部破冰/团建 | 零食饮品、小道具 | 小奖品 | 印刷大件、设备 |
| 技术分享/工作坊 | 茶歇、打印讲义 | 邀请礼品 | 场地、横幅 |
| 对外摆摊/展示 | 展架、印刷、宣传单 | 互动小奖品 | 场地（广场免费） |
| 品牌活动 | 奖品、宣传、布置 | 设备租赁 | — |
| 竞赛 | 奖品、评审费 | 场地布置、物料 | — |

**校验逻辑**：如果"内部例会"算出横幅+展架+奖品，说明结构错了；如果"竞赛"没有奖品预算，也说明漏了。

> ⚠️ 学期总预算 = 各活动之和，**不得超过社团联拨付额度**。超支需社长书面说明。

## 三、单价参考表（社团常用）

> 下表是**市场行情区间**，用于估算。实际采购价与渠道、时间、批量有关，**以实际询价为准**。报价时取区间中位数，并在「说明」列注明依据。

## 四、分级压缩方案（当用户要控制预算时）

用户说"控制在 X 元内"或"钱不够"时，**不要简单砍项交差**，要给出三档让用户选：

| 档位 | 做法 | 保留什么 | 砍掉什么 |
|------|------|---------|---------|
| **完整版** | 按实际需求全配 | 全部 | 无 |
| **标准版** | 保留核心体验，替换高价项 | 流程必需 + 关键奖品 | 定制类礼品、高单价零食 |
| **保底版** | 只保流程能跑通 | 流程必需物料、基础茶歇 | 奖品、纪念品、装饰 |

**每一档都要写清：砍掉之后活动体验损失了什么。** 例如：
> 保底版（719 元）：砍掉纪念钥匙扣与新奖品。损失：结束后没有可带走的物品，新成员记忆点变弱；建议改用电子纪念卡（0 成本）。

## 五、计算规则（严格执行）

1. 各项小计 = 数量 × 单价
2. **小计合计** = Σ 各项小计
3. 机动备用金 = 小计合计 × 10%
4. **总预算** = 小计合计 + 机动备用金
5. 四舍五入到整数元

> ❌ 禁止"备用金 = 总预算 × 10%"（循环引用）
> ✅ 正确："小计 1,518 元 × 10% = 152 元"

## 六、社团省钱策略（这一节最实用）

| 策略 | 预估节省 | 操作方式 |
|------|---------|---------|
| 场地全用校内免费 | 100% 场地费 | 教室/活动室/广场，提前 3 天申请 |
| 横幅改喷绘布复用 | 40-60% | 做通用款，多个活动共用 |
| 展架画面可换、架子复用 | 50% | 一次买架子，多次换画面 |
| 零食批发市场采购 | 15-25% | 校门口批发市场或网购整箱 |
| 用电子签到替代纸质 | 80% 印刷费 | 问卷星/腾讯文档 |
| 奖品选实用类 | 30-50% | 学生要"有用"，不要"好看" |
| 找会内技术好的同学设计 | 100% 设计费 | 海报、横幅自己出图 |
| 拉学生会/其他社团联办 | 30-50% | 分摊场地与物料 |
| 申请社团联专项支持 | 视情况 | 品牌活动可申请额外额度 |
| 用会费余额 | 视余额 | 需社长与财务知情 |

## 七、报销常见被退回原因

- 「其他费用」「杂项」等模糊科目 —— 必须逐项列明
- 数量与签到人数严重不符 —— 报销要附签到表
- 单价明显高于市场价，无说明
- 没有发票或只有收据 —— 需确认社团联认可的凭证类型
- 超预算未提前报批 —— 必须先申请后支出，不能先做后补
- 备用金未说明用途 —— 要写"用于不可预见支出，凭票据实报销"

## 八、社团预算的三个坑

1. **按最坏情况报预算，按最好情况执行** —— 报 800 实际花 400，下次审批会更严；建议如实估算。
2. **忘记留备用金** —— 现场物料不够临时补买，单价翻倍还报不了销。
3. **把个人垫付当常态** —— 长期垫付会打击干事积极性，能预支就预支。
