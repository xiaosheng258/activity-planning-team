# HTML 策划方案版式规范

最终交付物为**单个自包含 HTML 文件**，双击即可在浏览器打开，可直接打印 A4 或转 PDF 交老师。

## 骨架使用规则（主理人必读）

骨架文件 `策划书-HTML骨架.html` 不是填空模板，是**结构与样式的基线**。使用方法：

### 保留不动
- `<style>` 全部内容（除非用户明确要换配色）
- 各 `<section>` 的 `id`（目录锚点依赖它）
- `nav` 里的锚点列表

### 必须替换的占位符
| 占位符 | 替换为 | 注意 |
|--------|--------|------|
| `{{活动名称}}` | 活动全名 | 出现 2 次（title 与 h1） |
| `{{Slogan}}` | 一句话主张 | 无 Slogan 则删整个 `.slogan` 行 |
| `{{日期 时段}}` `{{场地}}` `{{人数}}` `{{主办单位}}` | 四要素 | 缺失写「待确认」 |
| `{{...}}` 段落 | 对应成员产出 | — |

### 表格行必须复制扩展
骨架里每个表格只有 1 行示例。**数据有几行就复制几行 `<tr>`**，不要只填第一行。

- 流程表：按主笔的流程节点逐条复制
- 物料表：按物料清单逐条复制
- 分工表：按分工逐条复制
- 预算表：按预算项逐条复制，**合计行用 `class="sum"` 且放在最后**
- 风险表：按风险项复制，等级单元格用对应 class

### 等级颜色映射（风险表）
```html
<td class="lv-high">高</td>   <!-- 红 -->
<td class="lv-mid">中</td>    <!-- 橙 -->
<td class="lv-low">低</td>    <!-- 绿 -->
```

### 待确认清单生成规则
凡是满足以下任一条件的，都要在文末「待确认事项」中列一条 `<li>`：
- 用户未提供、由模型推算的数字（人数、单价、电话）
- 标注过 `<待确认>` 的字段
- 需要用户线下确认的事项（场地、嘉宾、赞助）

每条后面加 `<span class="tag">待确认</span>`。

### 自检（渲染完必须逐条过）
- [ ] `{{` 和 `}}` 已全部清除，页面无残留占位符
- [ ] 每个表格的行数与对应成员产出的条目数一致
- [ ] 预算合计 = 各项之和 + 备用金（可用计算核对）
- [ ] 风险表至少 1 条标为「高」，否则说明在回避
- [ ] 目录 9 个锚点都能跳到对应 section
- [ ] 全文时间/地点/报名方式前后一致（方案 vs 宣传）

## 硬性要求

| 项 | 要求 |
|---|---|
| 文件 | 单个 `.html`，内部 `<style>`，不依赖外部 CDN、不联网即可正常显示 |
| 命名 | `策划书_<活动名>_<YYYYMMDD>.html` |
| 编码 | `<meta charset="utf-8">` |
| 字体 | 中文优先 `"Microsoft YaHei", "PingFang SC", "Source Han Sans SC", sans-serif` |
| 宽度 | 正文容器 `max-width: 900px`，居中 |
| 打印 | `@media print` 下隐藏按钮，表格不跨页断行，字号 11pt |
| 目录 | 顶部生成锚点目录，八段可点击跳转 |

## 必含区块（顺序不可变）

1. **封面头**：活动名称（大字）、Slogan、时间/地点/规模/主办四要素横排
2. **目录**：八段锚点
3. **正文八段**：一主题、二背景意义、三时间、四参与人员、五内容与流程、六活动准备、七预算、八注意事项
4. **风险预案表**（并入第八段）
5. **宣传文案**（作为附录 A）
6. **待确认事项清单**（如有信息缺失，红色标注）

## 视觉规范

- 主色：`#1e5b96`（深蓝），辅色 `#e8f0f8`（浅蓝底）
- 章节标题：左侧 4px 主色竖条 + `#1e5b96` 文字
- 表格：表头底色 `#e8f0f8`、边框 `#d0dbe8`、隔行浅灰
- 重点数字（预算合计、人数）：加粗 + 主色
- 风险等级：高 `#c0392b`、中 `#e67e22`、低 `#27ae60` 色标
- 所有表格加 `<caption>` 说明用途

## 排版细节

- 表格必须 `width:100%; border-collapse:collapse`，单元格 `padding:8px 12px`
- 长表格允许横向滚动（外层 `overflow-x:auto`）
- 预算表合计行加粗、底色 `#fff8e6`
- 打印时每个章节 `page-break-inside:avoid`（允许大节跨页，小表不拆）

## 反例（禁止）

- ❌ 只输出 Markdown 表格给用户，不生成 HTML 文件
- ❌ 用外部 CSS/JS CDN，断网就白屏
- ❌ 把五份产出原文直接堆进去，不做整合与去重
- ❌ 缺目录、缺封面头，像一份草稿
