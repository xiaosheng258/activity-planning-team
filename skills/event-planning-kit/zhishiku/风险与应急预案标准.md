# 校园活动风险与应急预案标准

> 供风险管控师（risk-manager）检索。风险识别必须覆盖以下四类全部来源，不得只挑几条凑数。

## 一、风险四类来源

### 1. 场地类
| 风险项 | 触发场景 | 典型后果 |
|--------|---------|---------|
| 场地临时被征用 | 学校临时会议/考试 | 活动无法进行 |
| 场地容量不足 | 报名超预期 | 拥挤、踩踏风险 |
| 消防通道堵塞 | 物料堆放 | 安全隐患，被叫停 |
| 地面湿滑/台阶 | 雨天、室外 | 摔伤 |
| 电力容量不足 | 多设备同时使用 | 跳闸断电 |

### 2. 人员类
| 风险项 | 触发场景 | 典型后果 |
|--------|---------|---------|
| 参与人数远超预期 | 宣传过度/无需报名 | 资源不足、失控 |
| 参与人数不足 | 宣传不到位/时间冲突 | 冷场、效果差 |
| 人员冲突/争执 | 竞争性环节、评奖争议 | 场面失控 |
| 身体不适/受伤 | 剧烈活动、高温 | 需医疗处置 |
| 嘉宾/评委缺席 | 临时变故 | 流程断裂 |
| 工作人员不足 | 排班失误 | 环节脱节 |

### 3. 设备类
| 风险项 | 触发场景 | 典型后果 |
|--------|---------|---------|
| 音响故障/啸叫 | 设备老化、调试不当 | 无法正常进行 |
| 投影无信号 | 接口不匹配、线材坏 | 内容无法展示 |
| 话筒没电/失声 | 未备电池 | 发言中断 |
| 断电 | 负载过大/线路故障 | 全场中断 |
| 网络中断 | 依赖在线系统 | 签到/投票失败 |

### 4. 流程与外部类
| 风险项 | 触发场景 | 典型后果 |
|--------|---------|---------|
| 环节严重超时 | 无时间控制 | 后续流程压缩 |
| 冷场/互动无响应 | 设计不合理 | 体验差 |
| 恶劣天气 | 室外活动 | 无法进行 |
| 舆情/投诉 | 评奖不公、宣传失误 | 负面影响 |
| 物料缺失 | 采购遗漏/未到位 | 环节无法执行 |

## 二、风险分级标准

| 等级 | 判定条件 | 应对要求 |
|------|---------|---------|
| 高 | 发生概率高 **且** 影响严重；或影响严重且无法事后补救 | 必须有预防措施 + 处置流程 + 备用方案 + 明确责任人 |
| 中 | 概率中等或影响可控制 | 需有处置流程 + 责任人 |
| 低 | 概率低且影响小 | 有预案即可，可并入其他条目 |

> 定级方法：概率（高/中/低）× 影响（严重/一般/轻微）。任一为"高"则整体不低于"中"；两者皆高则定为"高"。

## 三、应急联络基线

| 角色 | 联系方式 | 何时联系 |
|------|---------|---------|
| 校医院/医务室 | ⚠️ 待填 | 人员受伤、突发疾病 |
| 校园保卫处 | ⚠️ 待填 | 冲突、失窃、秩序失控 |
| 场地管理方 | ⚠️ 待填 | 设备故障、场地问题 |
| 活动总负责人 | ⚠️ 待填 | 一切重大决策 |
| 指导老师 | ⚠️ 待填 | 超出权限的事项 |

> ⚠️ 首次使用请填入真实号码，否则预案形同虚设。

## 四、标准处置流程

**人员受伤**：立即停止相关环节 → 就近简单处理 → 拨打校医电话 → 严重则送医并通知辅导员 → 保留现场记录

**设备故障**：切备用设备 → 无法切换则调整流程（如取消视频改为口头）→ 通知场控安抚

**人数超预期**：启用备用座位区 → 物料按实际人数重新分配（优先保障参与者）→ 必要时限制后续入场

**冲突争执**：工作人员介入隔离 → 带离现场单独沟通 → 涉及人身安全立即报保卫处

**断电**：确认是否全场 → 联系场地管理方 → 若 5 分钟内无法恢复，宣布暂停或改期

## 五、必备预案清单（按活动类型）

| 活动类型 | 必做预案 |
|---------|---------|
| 室外活动 | 雨天改期/转室内方案 + 风力预案 |
| 大型集会（200+） | 疏散路线 + 医疗点 + 安保对接 |
| 含剧烈运动 | 医疗处置流程 + 免责说明 |
| 含评奖 | 争议处理口径 + 评委回避机制 |
| 含餐饮 | 食品安全责任方 + 过敏原提示 |
| 有嘉宾出席 | 嘉宾缺席替代方案 |

## 六、常见预案通病（写的时候自查）

- 只写"加强管理""注意安全"，没有具体动作和责任人 → **无效预案**
- 风险项列了 10 条，全是"低"，回避了真正的高风险
- 没有备用方案，出事只能取消
- 应急电话写"联系相关部门"，没写号码
- 责任人是"全体工作人员"，等于没人负责
