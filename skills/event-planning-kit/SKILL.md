# event-planning-kit

活动策划天团共用的模板与规范包。把「策划书八段式」「预算表」「风险预案」「宣传文案」四种结构固化下来，确保每个团员产出格式统一、可直接拼装成最终 HTML 策划方案。

## 何时使用
- 主理人启动任意活动策划任务时预加载，作为全团统一的结构基线。
- 任一团员在撰写自己负责段落时，引用对应模板的字段与表格样式。

## 包含模板
- `references/策划书-HTML骨架.html` — **最终交付物骨架**，含完整内联样式（封面头/目录/八段/打印适配），主理人汇编时以此为基。
- `references/HTML方案版式规范.md` — HTML 方案的硬性要求、区块顺序、配色与打印规范、反例。
- `references/策划书八段式模板.md` — 策划书总框架（主题→背景→时间→人员→流程→准备→预算→注意事项），红字标注的颗粒度要求必须落实。
- `references/预算表模板.md` — 支出项目 / 数量 / 单价 / 总价 / 合计，含 10% 备用金。
- `references/风险预案模板.md` — 风险项 / 类型 / 等级 / 预防 / 处置 / 责任人 / 备用方案。
- `references/宣传文案模板.md` — 推送 / 海报 / 招募三段式结构。

## 知识库（zhishiku/）

每个角色有专属标准，**派单时必须把路径传给对应成员**，否则会凭记忆瞎编：

| 文件 | 使用者 | 内容 |
|------|--------|------|
| `zhishiku/活动统筹全流程标准.md` | proposal-writer | 活动分级、场地借用、审批流程、筹备里程碑、物料基线、常见失误 |
| `zhishiku/预算标准.md` | budget-analyst | 分级预算上限、五类单价参考、结构比例、计算规则、省钱策略 |
| `zhishiku/风险与应急预案标准.md` | risk-manager | 四类风险源清单、分级标准、应急联络、处置流程、预案通病 |
| `zhishiku/宣传文案标准.md` | promo-copywriter | 语气分档、五类标题公式、推送/海报/招募规范、自检清单 |

> 标 ⚠️ 的条目为通用估值，需按本校实际替换（尤其是预算上限与应急电话）。

## 输出目录

```
output/
├── 预算/            预算表_<活动名>.xlsx
├── 风险预案/        风险预案_<活动名>.xlsx
├── 宣传物料/        宣传_<活动名>.pptx
└── 策划书_<活动名>_<YYYYMMDD>.html
```

## 使用约定
1. 八段式顺序不可乱：一主题、二背景意义、三时间、四参与人员、五内容与流程、六活动准备、七预算、八注意事项。
2. 第四至第七段的红字要求（分工到人、联系方式、单价合计、发言到人）是硬性颗粒度，缺失视为不合格。
3. 预算与筹备金额必须互相印证；风险预案必须覆盖流程关键节点。
4. **最终交付必须是单个自包含 HTML 文件**，不能只给 Markdown 表；必须套用 `策划书-HTML骨架.html` 的样式。
5. 估算或缺失的信息在 HTML 中用「待确认」标签标注，不得伪装成确定数据。
6. **单价一律从知识库取**，不凭记忆估价。
