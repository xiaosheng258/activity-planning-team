# 校园活动宣传文案标准

> 供宣传文案师（promo-copywriter）检索。文案必须按本标准的语气分档和结构规范执行。

## 一、语气分档

| 人群 | 语气 | 典型词汇 | 忌讳 |
|------|------|---------|------|
| 大一新生 | 轻松、网感、有共鸣 | "主打一个""不整虚的""来了就是自己人" | 官腔、说教 |
| 在校生（通用） | 明快、信息密集 | "周五见""扫码占座""名额有限" | 拖沓铺垫 |
| 社团骨干 | 专业、讲价值 | "复盘""能力沉淀""项目落地" | 过度卖萌 |
| 老师/校方 | 正式、讲成效 | "育人""覆盖面""预期成效" | 网络用语 |
| 校外嘉宾 | 尊重、讲层次 | "诚邀""议程""交流" | 随意 |

## 二、推送文案结构（三段式）

```
【标题】一句话钩子，不超过 20 字
【钩子段】1-2 句戳中痛点或爽点
【信息段】时间 / 地点 / 对象 / 报名方式，用 emoji 或符号分隔
【行动段】明确下一步 + 时间紧迫感（如有）
```

**推送字数**：微信群版 200-300 字；公众号版 600-1000 字。

### 标题公式（任选其一）

| 公式 | 示例 |
|------|------|
| 痛点式 | "报了社团却一个认识的人都没有？" |
| 反差式 | "不搞讲座不排名，两小时纯玩" |
| 利益式 | "来了送钥匙扣，还能认识 8 个人" |
| 身份式 | "给 2026 级新生的一封邀请" |
| 悬念式 | "周五晚上，我们准备了一件小事" |

> ❌ 禁用标题："关于开展 XX 活动的通知""欢迎大家积极参加"——这是通知不是文案。

### 正文模板

```
[钩子] 明明报了社团，却一个认识的人都没有？我们懂。
[信息] 所以这次不搞讲座、不排名、不念稿子。
[卖点] 两小时，8 个小组，你画我猜技术梗版，输了要表演——主打一个笑着认识人。
[信息] ⏰ 11月13日 19:00
       📍 大学生活动中心多功能厅
       🎯 2026 级全体新成员
[行动] 扫码报名，11月10日 24:00 截止
```

## 三、海报文案规范

| 元素 | 字数限制 | 要求 |
|------|---------|------|
| 主标题 | 6-12 字 | 一眼记住，可作 Slogan |
| 副标题 | 10-20 字 | 补充说明活动性质 |
| 信息块 | — | 时间/地点/对象/报名，**必须全** |
| 主办方 | — | 放底部，字号最小 |

**必须包含**：主标题、副标题、时间、地点、报名方式、主办单位、视觉元素建议。

**配色建议方向**：
- 学术类：深蓝 + 白 + 少量金
- 文体类：亮橙/红 + 深色底
- 招新类：品牌色 + 高对比
- 公益类：绿色 + 暖白

## 四、招募话术规范

**场景**：私聊邀请、群内口播、摆摊介绍

**结构**（30 秒内说完）：
1. 一句话说清是什么（5 秒）
2. 一句话说清为什么值得来（10 秒）
3. 时间地点 + 降低决策门槛（10 秒）
4. 主动提供帮助（5 秒）

**示例**：
> "周五晚上有空吗？我们工作室办迎新，两小时，纯玩不推销。来了先认识 8 个人，还送个钥匙扣。地点就在活动中心，我帮你占座。"

**忌讳**：一口气报完所有流程、用"必须参加"施压、承诺做不到的事。

## 五、文案自检清单（提交前逐条过）

- [ ] 时间、地点、报名方式与策划书方案**完全一致**
- [ ] 没有夸大承诺（"包学会""必中奖"）
- [ ] 标题不是"关于XX的通知"式公文腔
- [ ] 目标人群明确，语气匹配
- [ ] 报名截止时间写清楚
- [ ] 主办单位署名
- [ ] 无错别字，标点统一（中文全角）
- [ ] 字数在要求范围内

## 六、常见问题

| 问题 | 修正方向 |
|------|---------|
| 通篇"为进一步丰富校园文化生活" | 删掉，直接说事 |
| 信息埋在第三段 | 时间地点提到前 3 行 |
| 没有行动指令 | 补"扫码报名""私信我" |
| 标题太长（30+ 字） | 砍到 20 字内 |
| 口号空洞（"青春飞扬"） | 换成具体画面 |
| 全篇感叹号 | 保留 1-2 个即可 |
