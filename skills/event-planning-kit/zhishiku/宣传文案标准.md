# 社团活动宣传文案标准

> 供宣传文案师（promo-copywriter）检索。语气分档必须按本表执行。
>
> 适用范围：**学生社团活动**。社团宣传的对手不是别的活动，是"刷手机"。三秒抓不住就划走了。

## 一、语气分档

| 受众 | 场景 | 语气 | 典型词汇 | 忌讳 |
|------|------|------|---------|------|
| 大一新生 | 招新、迎新、破冰 | 轻松、有共鸣、去官方 | "来了就是自己人""不整虚的""主打一个" | 官腔、"欢迎积极参加" |
| 社团内部成员 | 例会、培训、团建 | 直接、简短、像朋友喊话 | "周三晚老地方""带电脑""别迟到" | 长篇大论、正式格式 |
| 全校学生 | 竞赛、展览、讲座 | 亮价值、给理由 | "能带走什么""名额有限" | 自嗨、过度吹嘘 |
| 指导老师/社团联 | 报备、经费申请 | 正式、讲成效 | "覆盖面""预期成效""育人" | 网络用语、随意表达 |
| 校外嘉宾 | 讲座邀请 | 尊重、讲层次 | "诚邀""议程""交流" | 卖萌、过度熟络 |

## 二、推送文案结构（三段式）

```
【标题】一句话钩子，≤20 字
【钩子段】1-2 句，戳痛点或爽点
【信息段】时间 / 地点 / 对象 / 报名方式
【行动段】明确下一步 + 截止时间
```

**字数**：微信群版 150-300 字；公众号版 500-800 字。

### 标题公式（社团最常用前三种）

| 公式 | 示例 | 适用 |
|------|------|------|
| **痛点式** | "报了社团却一个认识的人都没有？" | 迎新、破冰 |
| **反差式** | "不搞讲座不排名，两小时纯玩" | 招新、团建 |
| **利益式** | "来了送钥匙扣，还能认识 8 个人" | 招新、摆摊 |
| 身份式 | "给 2026 级新生的一封邀请" | 迎新 |
| 悬念式 | "周五晚上，我们准备了一件小事" | 活动预热 |
| 问答式 | "想学 Python 但不知道从哪开始？" | 培训、分享 |

> ❌ 禁用标题："关于开展XX活动的通知""欢迎大家积极参加"——这是通知不是文案。

### 正文模板（招新/破冰类）

```
[钩子] 明明报了社团，却一个认识的人都没有？我们懂。
[反差] 所以这次不搞讲座、不排名、不念稿子。
[卖点] 两小时，8 个小组，你画我猜技术梗版，输了要表演——主打一个笑着认识人。
[信息] ⏰ 11月13日 19:00
       📍 大学生活动中心多功能厅
       🎯 2026 级全体新成员
[行动] 扫码报名，11月10日 24:00 截止
```

### 正文模板（内部通知类，简短直给）

```
【周三例会】
时间：周三 19:00
地点：活动室 302
内容：这周做爬虫实战，带电脑
备注：上次的作业记得交，没做的现场补
```

> 内部通知**不用包装**，越直接越好。写成长篇反而没人看。

## 三、海报文案规范

| 元素 | 字数 | 要求 |
|------|------|------|
| 主标题 | 6-12 字 | 一眼记住，可作 Slogan |
| 副标题 | 10-20 字 | 说明活动性质 |
| 信息块 | — | 时间/地点/对象/报名，**必须全** |
| 社团标识 | — | 放底部，logo + 名称 |

**必须包含**：主标题、副标题、时间、地点、报名方式、社团名称/logo、二维码占位。

**配色方向**：
- 技术类社团：深蓝/黑 + 亮色点缀，冷静专业
- 文艺类社团：暖色、留白多
- 体育类：高饱和、有动感
- 公益类：绿色/暖白，柔和
- 招新通用：高对比 + 品牌色，远看能认出来

## 四、招新话术规范（摆摊/私聊）

**结构**（30 秒内）：
1. 一句话说清是什么社团（5 秒）
2. 一句话说清能带走什么（10 秒）
3. 时间地点 + 降低决策门槛（10 秒）
4. 主动提供帮助（5 秒）

**摆摊示例**：
> "同学你好，我们是星海工作室，主要做编程和技术实践。这学期有 Python 入门课和项目组，大一的零基础也能跟上。今天扫码进群就行，不急着报名，先看看。"

**私聊示例**：
> "周五晚上有空吗？我们社团办迎新，两小时，纯玩不推销。来了先认识 8 个人，还送个钥匙扣。地点就在活动中心，我帮你占座。"

> **摆摊关键**：不要问"要不要加入"，先问"你是不是学 XX 专业的"——降低防备，再聊。

## 五、不同场景的文案重点

| 场景 | 重点是 | 不要写 |
|------|--------|--------|
| 招新宣传 | 门槛低、能学到什么、有归属感 | 复杂的技术术语、部门架构 |
| 活动预热 | 好奇心、悬念、时间紧迫 | 全流程细节 |
| 活动回顾 | 现场感、成果、感谢 | 流水账、领导讲话 |
| 内部通知 | 时间地点内容 | 大段铺垫 |
| 竞赛招募 | 奖项、含金量、评委阵容 | 空泛的"锻炼自己" |
| 成果展示 | 具体数字、实物图 | "取得圆满成功" |

## 六、文案自检清单

- [ ] 时间、地点、报名方式与策划书**完全一致**
- [ ] 没有夸大承诺（"包学会""必中奖""保证加分"）
- [ ] 标题不是"关于XX的通知"式公文腔
- [ ] 目标人群明确，语气匹配
- [ ] 报名截止时间写清
- [ ] 社团名称/logo 有
- [ ] 无错别字，标点中文全角
- [ ] 字数在范围内（群消息 150-300 字）

## 七、常见问题与修正

| 问题 | 修正 |
|------|------|
| "为进一步丰富校园文化生活" | 删掉，直接说事 |
| 信息埋在第三段 | 时间地点提到前 3 行 |
| 没有行动指令 | 补"扫码进群""私信我" |
| 标题 30+ 字 | 砍到 20 字内 |
| 口号空洞（"青春飞扬"） | 换具体画面（"8 个小组，你画我猜"） |
| 全篇感叹号 | 留 1-2 个 |
| 自嗨式吹嘘（"本社团实力雄厚"） | 换成事实（"去年做了 12 个项目"） |
