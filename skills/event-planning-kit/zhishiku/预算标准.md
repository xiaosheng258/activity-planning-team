## 三、预算结构参考比例

| 类别 | 占比建议 | 说明 |
|------|---------|------|
| 场地 | 0-10% | 校内场地通常免费 |
| 物料印刷 | 10-20% | — |
| 食品饮品 | 20-35% | 占比最高项，最易压缩 |
| 奖品 | 15-30% | 视评奖需要 |
| 设备 | 5-15% | — |
| 机动备用金 | 10% | **必留，不可省** |

## 四、计算规则（严格执行）

1. 各项小计 = 数量 × 单价
2. **小计合计** = Σ 各项小计
3. 机动备用金 = 小计合计 × 10%
4. **总预算** = 小计合计 + 机动备用金
5. 结果四舍五入到整数元

> ❌ 禁止写成"备用金 = 总预算 × 10%"（循环引用）
> ✅ 正确写法："小计 1,518 元 × 10% = 152 元"

## 五、省钱策略库

| 策略 | 预估节省 | 适用条件 |
|------|---------|---------|
| 校内场地替代校外 | 100% 场地费 | 优先考虑 |
| 零食批量批发 | 10-20% | 提前 3 天采购 |
| 印刷品合并下单 | 15-25% | 多项物料同批 |
| 用电子签到替代纸质 | 80% 印刷费 | 有网络条件 |
| 奖品换实用类替代品牌类 | 30-50% | 学生活动适用 |
| 借用社团库存物料 | 视库存 | 需提前盘点 |
| 寻找赞助 / 合作单位 | 10-100% | 提前 2 周谈 |

## 六、常见超标原因（写预算时规避）

- 按报名人数算物料，没留 10%-15% 冗余 → 现场不够临时补买，单价翻倍
- 忘记场地管理费、设备押金
- 定制物料没算开模费、丝印费
- 没留备用金，超支后无处消化
- 餐饮按"人均"估，没算工作人员和嘉宾
