# 社团活动统筹全流程标准

> 供方案主笔（proposal-writer）检索。标 ⚠️ 的按你社团实际替换。
>
> 适用范围：**学生社团活动**，两类并行——内部建设（迎新/培训/团建/例会）与对外展示（竞赛/展览/讲座/招新）。主力规模 30-80 人，社团联独立管理。

## 一、社团活动的两类场景

### A. 内部建设类（面向成员）

| 活动 | 规模 | 时长 | 核心目标 |
|------|------|------|---------|
| 迎新破冰 | 50-80 人 | 2-2.5 小时 | 消除陌生感，完成分组 |
| 新成员培训 | 20-40 人 | 2-3 小时 | 技能入门，形成学习小组 |
| 技术分享/例会 | 15-40 人 | 1.5 小时 | 知识传递，维持活跃度 |
| 期中团建 | 30-60 人 | 半天 | 增强归属感，缓解疲劳 |
| 学期总结/换届 | 30-80 人 | 2 小时 | 复盘、交接、表彰 |

### B. 对外展示类（面向全校）

| 活动 | 规模 | 时长 | 核心目标 |
|------|------|------|---------|
| 招新摆摊 | 不限（接触 200+） | 1-2 天 | 招新，品牌曝光 |
| 技术竞赛 | 50-150 人 | 半天-2 天 | 影响力，选拔人才 |
| 作品展/成果展 | 100-300 人 | 1-3 天 | 展示实力，争取资源 |
| 公开讲座 | 80-200 人 | 2 小时 | 外部连接，专业形象 |
| 联合活动 | 100-300 人 | 视情况 | 跨社团合作，扩大影响 |

> **两类活动的差异**：内部类重"体验与关系"，流程可灵活；对外类重"形象与可控"，每个环节都要有备案，因为对外活动出问题影响的是整个社团。

## 二、审批与报备流程（社团路径）

| 事项 | 找谁 | 提前多久 | 备注 |
|------|------|---------|------|
| 活动立项 | 社长/部长会 → 社团联备案 | 7 天 | 内部活动可简化 |
| 场地申请 | 教务系统 或 社团联 | 3-7 天 | 教室需任课教师同意 |
| 经费申请 | 社团联财务 | 7 天 | 附预算明细 |
| 对外活动报备 | 社团联 + 指导老师 | 14 天 | 需提交完整策划书 |
| 校外人员参与 | 指导老师 + 社团联 | 14 天 | 需说明来访目的 |
| 大型活动（200+） | 社团联 + 保卫处 | 21 天 | 需安全预案 |

> ⚠️ 各校社团联章程不同，首次办某类活动前先问社团联秘书处。

## 三、筹备里程碑（T = 活动当天）

### 内部建设类（周期短，可压缩）

| 时间 | 事项 |
|------|------|
| T-10 天 | 定方案、报社团联备案 |
| T-7 天 | 申请场地、发内部通知 |
| T-5 天 | 采购物料、招募志愿干事 |
| T-3 天 | 确认报名人数、分工到人 |
| T-1 天 | 彩排走位、打印签到表、备物料 |
| 当天 T-1h | 场地布置 |
| 当天 T+30min | 撤场、清点 |

### 对外展示类（周期长，必须留缓冲）

| 时间 | 事项 |
|------|------|
| T-21 天 | 立项、确定主题与形式 |
| T-14 天 | 提交策划书报备、申请场地、预算报批 |
| T-10 天 | 宣传物料设计完成、赞助洽谈 |
| T-7 天 | 宣传首发、报名启动、评委/嘉宾邀请 |
| T-5 天 | 物料下单采购 |
| T-3 天 | 物料到位、志愿者分组培训 |
| T-2 天 | 报名截止、名单确认、物料清点 |
| T-1 天 | 全流程彩排、设备联调 |
| 当天 T-2h | 布置场地、设备二测 |
| 当天 T+1h | 撤场、场地恢复、物料盘点 |

## 四、人员配置（社团实际人力）

社团通常只有 5-15 个能干活的骨干，**分工必须现实**：

| 规模 | 可用人手 | 配置 |
|------|---------|------|
| 30 人以下 | 3-4 人 | 主持 1、场控 1、物料/签到 1、机动 1 |
| 30-80 人 | 6-10 人 | 主持 1、签到 2、场控 2、物料 1、摄影 1、机动 2 |
| 80-200 人 | 12-20 人 | 分设签到组、引导组、场控组、物料组、宣传组 |
| 200 人以上 | 20 人+ | 需设现场总指挥，各组配组长 |

> **社团现实**：骨干往往身兼数职。分工表要标出"谁是主责、谁是替补"，避免一个人请假全线瘫痪。

## 五、物料基线清单

### 内部建设类（轻量）

**必备**：签到表/二维码、姓名贴、签字笔、垃圾袋
**氛围**：小装饰、背景音乐（手机+音箱）
**消耗**：矿泉水（人数×1.2）、零食（人数×1.1）
**活动道具**：按游戏设计（卡片、道具、计分板）

### 对外展示类（重量）

**必备**：展架、横幅、宣传单页、签到表、工作证
**展示**：作品/成果实物、演示设备、易拉宝
**音视频**：音响、话筒（含备用电池）、投影、转接线
**接待**：矿泉水、席卡、礼品袋
**应急**：创可贴、纸巾、备用电源、胶带

> 备用量：消耗品 +10-15%，印刷品 +20%

## 六、时间安排建议（社团场景）

| 活动类型 | 推荐时段 | 避开 |
|---------|---------|------|
| 内部例会/培训 | 工作日晚 19:00-21:00 | 考试周、节假日前后 |
| 迎新破冰 | 开学第 2-3 周，周末下午或晚 | 军训期、开学第一周 |
| 对外讲座 | 工作日晚或周末下午 | 与校历重大活动撞期 |
| 摆摊招新 | 开学初、午间 11:30-13:30 | 雨天、考试周 |
| 竞赛 | 周末全天 | 期末周 |
| 团建 | 周末半天 | 与其他社团活动撞期 |

> **撞期检查必做**：办活动前查校历 + 问社团联近期活动安排，撞车是最常见的"人少"原因。

## 七、社团特有的失败模式（写方案时自查）

- **骨干不够**：按 20 人分工，实际只有 6 人干活 → 分工必须基于真实可用人力
- **撞期**：和校级活动/其他社团撞了，来的人不到一半
- **宣传太晚**：T-3 才发通知，报名不足
- **经费没批就花钱**：先垫付后报销，社团联不认
- **对外活动无备案**：出问题社团担责，社长受影响
- **老人不来**：只通知新成员，缺乏"老人带新人"机制
- **没有复盘**：办完就散，下次从零开始
- **物料一次一买**：横幅展架重复采购，浪费经费

## 八、复盘模板（每次活动后 3 天内做）

| 项 | 内容 |
|----|------|
| 到场人数 | 报名 X / 实到 Y，流失率 |
| 预算执行 | 预算 X / 实际 Y，偏差原因 |
| 流程问题 | 哪个环节超时/卡顿 |
| 人员问题 | 谁没到位、谁超负荷 |
| 反馈收集 | 参与者 3 条好评/差评 |
| 可复用资产 | 哪些物料能留到下次 |
| 下次改进 | 具体 2-3 条动作 |
