# 社团活动预算标准

> 供预算分析师（budget-analyst）检索。**所有单价必须从此处取，不要凭模型记忆估价。** 标 ⚠️ 的按你社团/学校实际替换。
>
> 适用范围：**学生社团活动**，经费由社团联合会独立管理，主力规模 30-80 人。

## 一、社团经费规则

| 项目 | 说明 |
|------|------|
| 经费来源 | 社团联按学期拨付 + 会费 + 赞助，⚠️ 有独立经费池 |
| 申请方式 | 活动前提交《活动经费申请表》，**需附预算明细** |
| 审批链 | 社长签字 → 指导老师知会 → 社团联财务审批 |
| 拨付方式 | ⚠️ 多数为**先垫付后报销**，少数可预支 50% |
| 报销凭证 | 发票 + 清单 + 签到表（证明实际发生） |
| 结余处理 | 顺延至下次活动，不得挪作他用 |

> **执行含义**：预算表必须"能报销"——每项要有发票来源、单价能对上、数量能说清。写"其他费用 500 元"这种会被打回。

## 二、社团活动经费档位

| 活动类型 | 单次预算参考 | 典型场景 |
|---------|------------|---------|
| 内部例会/培训 | ⚠️ 0-200 元 | 茶歇、打印材料 |
| 内部破冰/团建 | ⚠️ 300-800 元 | 零食、道具、小奖品 |
| 技术分享/工作坊 | ⚠️ 200-600 元 | 打印、茶歇、小礼品 |
| 对外展示/摆摊 | ⚠️ 500-1,500 元 | 展架、印刷、互动小奖品 |
| 品牌活动（年度） | ⚠️ 2,000-5,000 元 | 场地布置、奖品、宣传、设备 |
| 竞赛类 | ⚠️ 1,500-4,000 元 | 奖品、评审、场地、物料 |

> ⚠️ 学期总预算 = 各活动之和，**不得超过社团联拨付额度**。超支需社长书面说明。

## 四、预算结构参考（社团活动）

| 类别 | 建议占比 | 说明 |
|------|---------|------|
| 场地 | **0%** | 社团几乎不用付费场地 |
| 印刷物料 | 15-25% | 横幅、海报、展架 |
| 食品饮品 | 30-45% | 占比最高，最易压缩 |
| 奖品 | 15-25% | 竞赛/互动类才需要 |
| 设备 | 0-10% | 尽量借 |
| 机动备用金 | 10% | **必留** |

## 五、计算规则（严格执行）

1. 各项小计 = 数量 × 单价
2. **小计合计** = Σ 各项小计
3. 机动备用金 = 小计合计 × 10%
4. **总预算** = 小计合计 + 机动备用金
5. 四舍五入到整数元

> ❌ 禁止"备用金 = 总预算 × 10%"（循环引用）
> ✅ 正确："小计 1,518 元 × 10% = 152 元"

## 六、社团省钱策略（这一节最实用）

| 策略 | 预估节省 | 操作方式 |
|------|---------|---------|
| 场地全用校内免费 | 100% 场地费 | 教室/活动室/广场，提前 3 天申请 |
| 横幅改喷绘布复用 | 40-60% | 做通用款，多个活动共用 |
| 展架画面可换、架子复用 | 50% | 一次买架子，多次换画面 |
| 零食批发市场采购 | 15-25% | 校门口批发市场或网购整箱 |
| 用电子签到替代纸质 | 80% 印刷费 | 问卷星/腾讯文档 |
| 奖品选实用类 | 30-50% | 学生要"有用"，不要"好看" |
| 找会内技术好的同学设计 | 100% 设计费 | 海报、横幅自己出图 |
| 拉学生会/其他社团联办 | 30-50% | 分摊场地与物料 |
| 申请社团联专项支持 | 视情况 | 品牌活动可申请额外额度 |
| 用会费余额 | 视余额 | 需社长与财务知情 |

## 七、报销常见被退回原因

- 「其他费用」「杂项」等模糊科目 —— 必须逐项列明
- 数量与签到人数严重不符 —— 报销要附签到表
- 单价明显高于市场价，无说明
- 没有发票或只有收据 —— 需确认社团联认可的凭证类型
- 超预算未提前报批 —— 必须先申请后支出，不能先做后补
- 备用金未说明用途 —— 要写"用于不可预见支出，凭票据实报销"

## 八、社团预算的三个坑

1. **按最坏情况报预算，按最好情况执行** —— 报 800 实际花 400，下次审批会更严；建议如实估算。
2. **忘记留备用金** —— 现场物料不够临时补买，单价翻倍还报不了销。
3. **把个人垫付当常态** —— 长期垫付会打击干事积极性，能预支就预支。
