# 社团活动风险与应急预案标准

> 供风险管控师（risk-manager）检索。四类风险源必须覆盖，不得只挑软柿子。
>
> 适用范围：**学生社团活动**，30-80 人为主，社团联独立管理。社团最容易出问题的不是"安全事故"，而是**人不够、没人来、钱报不了**。

## 一、风险四类来源

### 1. 场地类

| 风险项 | 触发场景 | 典型后果 |
|--------|---------|---------|
| 场地临时被征用 | 学校临时开会/考试 | 活动无法进行 |
| 场地容量不足 | 报名超预期 | 拥挤、体验差 |
| 教室设备缺失 | 未提前确认投影/音响 | 演示无法进行 |
| 场地申请被拒 | 申请太晚/理由不充分 | 活动取消 |
| 室外天气 | 摆摊/户外团建遇雨 | 无法进行 |
| 场地清理不达标 | 撤场不彻底 | 社团被投诉、影响下次申请 |

### 2. 人员类（社团最高发）

| 风险项 | 触发场景 | 典型后果 |
|--------|---------|---------|
| **骨干不足** | 多人临时请假/考试 | 环节脱节，主力超负荷 |
| **参与人数不足** | 宣传晚、撞期、吸引力不够 | 冷场，效果差 |
| 参与人数超预期 | 宣传过度/无需报名 | 物料不够，场面失控 |
| 内部冲突 | 分工不均、评奖争议 | 团队关系受损 |
| 受邀嘉宾缺席 | 临时变故 | 流程断裂 |
| 新成员流失 | 只来一次就不再参与 | 活动白办 |
| 工作人员迟到 | 无考勤机制 | 开场混乱 |

### 3. 设备与物料类

| 风险项 | 触发场景 | 典型后果 |
|--------|---------|---------|
| 音响故障/啸叫 | 借用设备老化 | 无法正常进行 |
| 话筒没电 | 未备电池 | 发言中断 |
| 投影无信号 | 接口不匹配 | 内容无法展示 |
| 物料未按时到 | 采购太晚/快递延误 | 环节无法执行 |
| 物料数量不够 | 未留冗余 | 现场临时补买 |
| 展架被风吹倒 | 室外摆摊 | 损坏、有安全隐患 |
| 横幅挂设违规 | 未申请/位置不当 | 被要求拆除 |

### 4. 流程与合规类（社团特有）

| 风险项 | 触发场景 | 典型后果 |
|--------|---------|---------|
| **经费未批就支出** | 先花钱后报销 | 社团联不予报销 |
| **对外活动未报备** | 跳过社团联/指导老师 | 社团担责，社长受影响 |
| 免费承诺无法兑现 | 宣传时承诺赠品/餐食 | 失信，影响口碑 |
| 与校级活动撞期 | 未查校历 | 参与人数腰斩 |
| 环节严重超时 | 无时间控制 | 后续压缩、体验崩 |
| 冷场/互动无响应 | 设计不合理 | 体验差 |
| 舆情/投诉 | 评奖不公、宣传失误 | 负面扩散，影响招新 |

## 二、风险分级标准

| 等级 | 判定 | 应对要求 |
|------|------|---------|
| 高 | 概率高且影响严重；或损失不可挽回（如合规问题、对外形象） | 预防 + 处置 + 备用方案 + 唯一责任人，**必须写进方案** |
| 中 | 概率中等或影响可控制 | 处置流程 + 责任人 |
| 低 | 概率低且影响小 | 有预案即可 |

> 定级方法：概率（高/中/低）× 影响（严重/一般/轻微）。任一为"高"则整体不低于"中"。
>
> **社团特殊规则**：涉及"合规/报销/对外形象"的风险，即使概率低，也**至少定为中**——因为这类问题会连累整个社团，不只是这一场活动。

## 三、应急联络（不写死号码，写清"谁负责拿到号码"）

社团没有固定的应急通讯录，每次活动都不同。**不要写"⚠️待填"，要写成明确的责任动作：**

| 角色 | 谁负责确认 | 什么时候确认 |
|------|-----------|-------------|
| 活动总负责人（社长/项目负责人） | 方案里直接写名字 | 立项时 |
| 现场场控 | 指定到具体人 | 分工时 |
| 指导老师 | 社长 | T-3 天 |
| 社团联对接人 | 社长/秘书 | T-3 天 |
| 校医院/医务室 | 场控 | T-1 天，查清位置和电话 |
| 校园保卫处 | 场控 | T-1 天 |
| 场地管理方 | 场地负责人 | 场地申请通过时 |

**输出要求**：应急联络表写成下面这样，而不是空着等填：

```
| 角色 | 责任人 | 联系方式 | 确认状态 |
|------|--------|---------|---------|
| 活动总负责人 | 社长（姓名） | 由本人提供 | 立项时确认 |
| 现场场控 | XX | 由本人提供 | 分工时确认 |
| 校医/医务室 | 场控负责查 | T-1 天查明并记录 | 待确认 |
```

> **核心**：Plan 里写明"谁在什么时候把号码拿到手"，比写一串空白的"待填"有用得多。真出事时，知道该找谁要号码，比知道"号码待填"强。

## 医疗与安全兜底（不依赖具体号码）

- **就近原则**：活动前确认"最近的医务室/医院在哪、怎么走"，写进方案
- **陪护原则**：任何人员送医，必须至少 1 名工作人员陪同
- **留证原则**：受伤事件当场拍照、记录时间地点经过，事后交社团联
- **报备原则**：涉及送医的情况，2 小时内报指导老师与社团联

## 四、标准处置流程

**骨干临时缺席**：启用事先指定的替补 → 该成员环节由主责人接管或简化 → 事后不追责但要记录，下次排班规避

**人数远低于预期**：转到"小规模模式"（减少分组、缩短游戏）→ 不要硬撑原流程 → 事后分析原因（撞期？宣传？）

**人数超预期**：启用备用座位 → 物料按实际人数重分配（优先保障参与者）→ 必要时限制后续入场

**经费报销被拒**：当场记录凭证 → 3 天内找社团联沟通补正 → 不予通过的金额由社团经费盘亏，不向干事个人摊派

**对外活动被叫停**：立即停止 → 服从管理方要求 → 社长向社团联说明 → 保留书面记录

**设备故障**：切备用设备 → 无法切换则调整流程（视频改口头）→ 场控安抚

**天气突变（室外）**：启动改期或转室内 → 已在场则缩短流程 → 通过群公告通知未到场者

## 五、按活动类型的必备预案

| 活动类型 | 必做预案 |
|---------|---------|
| 迎新破冰 | 人数不足时的小规模方案、冷场备选游戏 2 个 |
| 培训/分享 | 讲师缺席替代方案、设备故障备用 |
| 团建 | 天气预案、人员受伤处置 |
| 摆摊招新 | 雨天预案、展架防风加固、物料补充方案 |
| 竞赛 | 评审争议口径、参赛人数不足/超额的调整规则 |
| 讲座 | 嘉宾缺席替代、场地容纳不足的转场方案 |
| 户外活动 | 雨天改期、高温/低温预案、医疗处置 |

## 六、预案通病（写的时候自查）

- 只写"加强管理""注意安全"，没有具体动作和责任人 → **无效**
- 风险列了 10 条全是"低"，回避了"骨干不够""没人来"这些真问题
- 没有备用方案，出事只能取消
- 应急电话写"联系相关部门"
- 责任人是"全体工作人员"——等于没人负责
- 忘了"合规类"风险（报销、报备），这恰恰是社团最常踩的坑

## 七、社团风险的三条铁律

1. **人是最不稳的变量**：所有环节都要有替补，不能靠"某某肯定会来"。
2. **先批后花，先报后备**：经费和报备的顺序不能颠倒，这是社团踩坑第一名。
3. **对外活动代表整个社团**：内部活动翻车是体验问题，对外活动翻车是社团形象问题，标准要高一档。
